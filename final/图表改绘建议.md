## 全部表格

| 标签 | 内容 | 可以怎样改绘 | 约束 |
|---|---|---|---|
| tab:symbols | 符号说明 | 按状态、物性、几何、数值量分组 | 保留符号/说明/单位三列；区分ρ与ρ_d |
| tab:q1T | 第一问温度 | 1800s行浅灰强调 | 题目规定行列；四位小数 |
| tab:q1C | 第一问水分 | 浅色突出近表面失水 | 不把2.5500解释为严格不变 |
| tab:q2T | 第二问温度 | 与水分表列宽对齐 | 0.5h间隔；不同于第一问物性 |
| tab:q2C | 第二问水分 | 3h行强调 | 单位和位置与温度表相互对应 |
| tab:q3 | 固定域全程水分 | 末行粗体、阈值以上轻度着色 | 末行是临界时刻，不能误称严格小于 |
| tab:q4 | 收缩域水分 | 半径列分隔、表面列浅蓝 | 表面为R(t)，域外位置不得补零 |
| tab:grids | 网格与时长 | 均匀/加密分组，可附收敛点图 | 不把不同网格族拟合为单一收敛阶 |
| tab:errors | 最大输出差 | 同单位分组、科学计数对齐 | 区分实际位置与参考坐标；差值不是严格上界 |
| tab:sensitivity | 环境延长对照 | 可加哑铃图展示两方案差异 | 数据来自已有640区间对照 |
| tab:final | 核心结论 | 温湿和时长分两组 | 与正文一致，时间为临界时间 |
| tab:files | 文件说明 | 可改简洁清单 | 不需要另造图形；保留来源对应关系 |

## 可选替换图

- 已有第一问温度/水分时空图可替换重复曲线，但不建议同时增加，避免超过30页。
- 若将来取得实验数据，可加入测量—预测对照；当前没有内部温湿实验，不应虚构。
- 若后续重算相同物性下有无收缩的对照，才能画收缩独立贡献图；现有结果不支持因果分离。

## 技术约定

1. 优先嵌入字体的矢量PDF；中文随图嵌入，避免换机缺字。
2. 正文图宽建议140—160mm，最终字号至少8—9pt，单位放轴标题。
3. 保持figures中的文件名与LaTeX标签；流程图可直接编辑TikZ。
4. 替换后编译两次，重新检查总页数、引用与页脚碰撞。
