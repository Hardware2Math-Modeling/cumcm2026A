## 0. 三层命名映射（本文件最重要的部分）

同一个物理量在三个地方有三个写法，**必须能一一对应**：

| 论文符号 | LaTeX 宏（`paper/preamble.tex`） | Python 变量名 | 含义 |
|---|---|---|---|
| $T$ | `\T` | `T` | 药材温度 |
| $C$ | `\C` | `C` | 水分浓度（干基含水率） |
| $t$ | `\t` | `t` | 时间 |
| $r$ | `\rpos` | `r` | 到药材中心的径向距离 |
| $R$ | `\R` | `R` | 药材半径（问题 4 中随时间变化） |
| $R_0$ | `\Rzero` | `R0` | 初始半径 |
| $L$ | `\Llen` | `L` | 药材长度 |
| $\rho$ | `\rho` 原生 | `rho` | 密度 |
| $c_p$ | `\cp` | `cp` | 定压比热容 |
| $k$ | `\kcond` | `k` | 导热系数 |
| $D$ | `\Ddiff` | `D` | 水分扩散系数 |
| $h$ | `\hconv` | `h_conv` | 对流换热系数 |
| $h_m$ | `\hmass` | `h_mass` | 对流传质系数 |
| $T_\infty$ | `\Tinf` | `T_amb` | 烘房（环境）温度 |
| $C_\infty$ | `\Cinf` | `C_amb` | 烘房（环境）水分浓度 |
| $w$ | `\wfrac` | `w` | 水分质量分数 $= C/(1+C)$ |

| $\Delta r$ | `\dr` | `dr` | 空间步长 |
| $N_r$ | `\Nr` | `N_r` | 径向网格节点数 |

> **规则**：论文里**不要**直接写 `$T$`，写 `\T`。这样一旦改名，只需改 `preamble.tex` 一处，全文自动同步。
> 代码变量名严格按上表，**不要用 `temp`、`moisture`、`conc` 这类自造名**。

## 2. 状态变量

| 符号 | 含义 | 单位 | 初值 | 备注 |
|---|---|---|---|---|
| $T(r,t)$ | 药材内部温度场 | °C（展示）/ **K**（代码） | 28 °C | 题目给出 |
| $C(r,t)$ | 药材内部水分浓度 | kg/kg（干基） | 2.55 kg/kg | 题目给出。定义为**水质量 / 干物质质量** |
| $w$ | 水分质量分数 | kg/kg | 由 $C$ 换算 | $w = C/(1+C)$。经验公式里出现的是 $w$，**不要和 $C$ 混淆** |

> ⚠️ **$C$ 与 $w$ 的区别是本项目最容易出的代数错误。**
> `ρ = 650 + 128C` 用的是 **$C$**（干基），而 `c_p = 1450 + 2736·C/(C+1)` 里的 `C/(C+1)` 就是 **$w$**（湿基）。
> 附录 3/4 的四个公式混用了两种表述，抄公式时必须逐个确认。

## 6. 单位换算（只在输入/输出边界使用）

```python
# 唯一允许的换算位置：src/common/units.py
CM_TO_M   = 1.0e-2
M_TO_CM   = 1.0e2
S_TO_H    = 1.0 / 3600.0
H_TO_S    = 3600.0
K_TO_C    = -273.15     # T_celsius = T_kelvin + K_TO_C
C_TO_K    = +273.15
```

**规则**：
- 代码内部计算**一律 SI，长度用 m，温度用 K**。
- 只在写入 `result*.xlsx` 和画图时转成 cm / °C / h。
- **禁止在 `src/q*/` 里写 `0.01` 或 `273.15` 字面量**，用 `units.py` 的常量。
