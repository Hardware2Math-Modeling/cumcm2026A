## 这里的文件是「交接契约」，不是笔记

`@impl` 会**照着这里的公式写代码**，`@paper` 会**照着这里的推导写论文**。
所以本目录的文件有一条硬标准：

> **每一行公式都必须能被逐行翻译成代码，或逐行排版成论文。**

反面例子（**不合格**）：

> "考虑用有限差分法求解该传热方程，边界条件采用对流换热。"

正面例子（**合格**）：

> 对 $r$ 方向采用中心差分，节点 $i=0,\dots,N$，$r_i = i\Delta r$：
> $$\frac{T_i^{n+1}-T_i^n}{\Delta t} = \frac{\theta}{\rho_i c_{p,i}}\frac{1}{r_i}\frac{1}{\Delta r}\left[k_{i+1/2}r_{i+1/2}\frac{T_{i+1}^{n+1}-T_i^{n+1}}{\Delta r} - k_{i-1/2}r_{i-1/2}\frac{T_i^{n+1}-T_{i-1}^{n+1}}{\Delta r}\right] + (1-\theta)(\cdots)$$
> 其中 $r_{i\pm1/2}=(r_i+r_{i\pm1})/2$，物性 $k_{i\pm1/2}$ 取相邻节点算术平均。
> **轴心处 $r=0$ 的奇性**：由对称性 $\partial T/\partial r = 0$，对控制体积做积分得
> $$\frac{T_0^{n+1}-T_0^n}{\Delta t} = \frac{\theta}{\rho_0 c_{p,0}}\frac{4k_{1/2}(T_1^{n+1}-T_0^{n+1})}{\Delta r^2} + \cdots$$

## 交接检查清单

在把本目录的文件交给 `@impl` 之前，逐条确认：

- [ ] 所有符号都在 `docs/NOTATION.md` 里有定义，**没有自造符号**
- [ ] 所有单位都明确（尤其：$T$ 是 K 还是 °C，$r$ 是 m 还是 cm）
- [ ] 所有带指数项的公式都确认了温度单位（`e^{-3850/T}` 的 $T$ 必须是 K）
- [ ] 离散格式具体到系数，不留"用差分处理"这种话
- [ ] 边界条件的离散形式写明（虚拟节点法/单侧差分，具体系数）
- [ ] 非线性项的处理策略写明（显式滞后 / Newton / 固定点迭代 + 收敛判据）
- [ ] 给出了 `@impl` 可执行的验证项（守恒量、精度阶、极限情形）
- [ ] 涉及的每个悬而未决的选择都在 `docs/DECISIONS.md` 里有对应条目
