## 1. ⚠️ $C$ 与 $w$ 的辨析（本项目最高频的代数错误来源）

题目定义 $C$ 为**干基含水率**（水分浓度）：$C = m_{\text{水}}/m_{\text{干物质}}$，单位 kg/kg。

经验公式里同时出现了两种表述：
- 直接用 $C$：如 $\rho = 650 + 128C$
- 用 $C/(C+1)$：这实际上就是**湿基质量分数** $w = \dfrac{C}{1+C} = \dfrac{m_{\text{水}}}{m_{\text{水}}+m_{\text{干物质}}}$

| 公式 | 用的是 | 说明 |
|---|---|---|
| $\rho = 650 + 128C$ | $C$（干基） | 直接线性 |
| $c_p = 1450 + 2736\cdot\frac{C}{C+1}$ | $w$（湿基） | 展开为 $1450 + 2736w$ |
| $k = 0.21 + 0.38\cdot\frac{C}{C+1}$ | $w$（湿基） | 展开为 $0.21 + 0.38w$ |

**实现规则**：`correlations.py` 的接口一律收 **$C$（干基）**，函数内部自己算 $w = C/(1+C)$。**不要把这个负担丢给调用方**，否则必然有人在某处传错。

## 5. ⚠️ $\rho$ 的双重含义（阻塞项 D-001）

附录给的 $\rho$ 是**含湿药材的表观密度**，随 $C$ 变化。
但扩散方程 $\partial C/\partial t = \frac{1}{r}\frac{\partial}{\partial r}\left(Dr\frac{\partial C}{\partial r}\right)$ 的推导前提是**干基密度 $\rho_d$ 为常数**。

本文件必须给出明确结论：⬜（见 `docs/DECISIONS.md` D-001）
