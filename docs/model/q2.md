## 4. 定解条件

### 4.1 初始条件
⬜ 预热阶段起点用题目给的 28 °C、2.55 kg/kg；恒温阶段起点用预热阶段的终态（**需说明连续性如何处理**）

### 4.2 边界条件
- $r = 0$：⬜ 对称性
- $r = R$：⬜
  - 热边界：对流 + **蒸发耗热**（D-002）
  - 质边界：对流传质 $-\rho_d D\frac{\partial C}{\partial r} = h_m(C_s - C_\infty)$ 或类似形式

> ⚠️ 若热边界含蒸发项，**热边界与质边界就耦合了**，这会显著影响干燥后期的表面温度。
> 这是本问最关键的建模选择，**必须在 `docs/DECISIONS.md` D-002 里定稿后再写代码**。
