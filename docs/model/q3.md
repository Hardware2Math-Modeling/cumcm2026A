# 问题三：全场干燥终点

Owner：`@model`。2026-09-11。完全沿用 q2.md 的附录 3、初值、自主温湿度、供水/气膜互补通量及汽化潜热，只改变输出频率与需报告的派生量。

## 1. 全场判据

$$M(t)=\max_{0\le r\le R_0}C(r,t),\qquad t_*=\inf\{t:M(t)<0.15\}.$$

连续场在阈值 t* 通常恰取 M=0.15，“严格低于”发生在其后。若工况切换导致暂时非单调，不能把一次向下过零未经检查视为永久达标。应保存 M(t) 并检查后续；事件使用全部内部网格最大值，而非先验写死中心最慢。

采用单次积分与向下过零事件 M(t)-0.15 定位阈值，利用积分器连续解求根。事件后继续至下一个输出时刻，确认该时刻严格合格。若范围内没达到条件，必须报错并记录，不能返回末时刻作答案。

## 2. 验证

空间与时间设置见 numerics.md。除场差外比较细化网格前后 t* 差；事件求根精度不等于 PDE 精度，同网格 BDF/Radau 只检查时间积分误差。四位小数只是显示格式，不代表物理时长精确至0.0001 h。

检查全场最大值、非负性、径向单调性和阈值两侧符号。与问题二相同时间的场必须一致。网格验证必须重做，旧无潜热结果失效。温湿工况及低含水率闭合不确定性作为模型敏感性，不能与离散误差混淆。
