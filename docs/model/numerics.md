# 四问共用数值规格

用户于2026-09-10确认：一维有效传热传质、纯对流热边界、题给浓度差的有效传质边界、四问沿用附录2对流系数；4小时以后环境末值保持；第四问域外留空。

## 模型

固定域：rho cp T_t=(r k T_r)_r/r，C_t=(r D C_r)_r/r。
轴心T_r=C_r=0；表面k T_r=h(T_inf-T_s)，D C_r=-h_m(C_s-C_inf)。
初值T=301.15 K，C=2.55。热方程采用有效显热容量，不声称是包含蒸发、骨架和水焓输运的完整热力学守恒方程。
题给气相和固相的kg/kg基准未明确相同；有效Robin边界是经用户确认的闭合假设，不能声称已证明基准一致。
经验rho仅用于热方程，干基水质量在固定域按常数参考干物质密度加权；不使用rho*C作为水质量。

第四问假设长度不变、径向均匀材料收缩：v=r Rdot/R，rho_d(t)=rho_d(0)(R0/R)^2。
由干物质连续性和水分守恒得C_t+v C_r=(r D C_r)_r/r。
令xi=r/R(t)，物质导数中的收缩输运项与链式法则项抵消，故
C_t|xi=(xi D C_xi)_xi/(R² xi)，rho cp T_t|xi=(xi k T_xi)_xi/(R² xi)。
表面D C_xi=-R h_m(C_s-C_inf)，k T_xi=R h(T_inf-T_s)。
不得在这个材料坐标模型上再次添加xi Rdot/R C_xi；该项仅对应没有材料速度的另一种欧拉模型。
均匀参考干密度用于质量审计，附录4经验rho不另被强行施加为局部干密度闭合。

## 节点中心有限体积

xi_i=1-(1-i/(N_r-1))²，i=0..N_r-1（**表面二次加密**，非均匀网格；用于解析干燥后期
低D区域在表面附近的薄边界层）。界面xi_{i+1/2}=(xi_i+xi_{i+1})/2，两端界面为0、1。
V_i=(xi_{i+1/2}²-xi_{i-1/2}²)/2。界面k、D取算术平均。
F^T_{i+1/2}=xi_{i+1/2} k_{i+1/2}(T_{i+1}-T_i)/(xi_{i+1}-xi_i)，F^C同理（**步长逐单元不同**）。
左端F=0；右端F^T=R h(T_inf-T_s)，F^C=-R h_m(C_s-C_inf)。
dT_i/dt=(F^T_right-F^T_left)/(R² V_i rho_i cp_i)，
dC_i/dt=(F^C_right-F^C_left)/(R² V_i)。
轴心控制体积自动得到4D(C_1-C_0)/Delta r²，不直接求1/r。
内部通量逐项抵消；同时积分损失率h_m(C_s-C_inf)/R，检查sum(V_i C_i)+累计损失守恒。
Q1同时积分R h(T_inf-T_s)，检查rho cp R² sum[V_i(T_i-T0)]等于累计加热。
Q2—4的变容量热方程验证瞬时离散收支，不错误宣称rho cp T的积分守恒。

## 积分与验证

使用SciPy BDF、稀疏数值Jacobian，默认相对容差2e-9、绝对容差2e-10，前4小时最大步长30s、以后120s。
输入附件作分段线性插值，越过4小时外推接点重启积分。求解器实际步长自适应，与输出步长不同。
基准网格及加密网格对比，记录最大场差和终点差；另收紧时间误差与最大步长以分离时间误差。
以全内部网格max(C)-0.15的向下过零事件确定阈值时刻，严格小于对应阈值之后。
xlsx延伸到首个严格合格的均匀输出点；报告同时给连续阈值时刻和输出网格合格时刻。
四位小数是输出格式，不等于物理预测精度；必须同时披露离散误差。
