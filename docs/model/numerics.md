# 四问共用数值规格：潜热与供水/气膜互补版

Owner：@model。2026-09-11。当前正式模型见q1—q4.md及environment.md。旧pure-convection/effective-radial-v1的物理解、误差表与无潜热Bessel参考不用于证明本次解已通过验证；可保留为明确关闭潜热与旧边界的独立极限测试。

## 1. 固定域与材料域

Q1—3以R=R0，Q4以附件R(t)；xi=r/R。材料域方程

$$\rho c_p T_t|_\xi=\frac{(\xi kT_\xi)_\xi}{R^2\xi},\qquad
C_t|_\xi=\frac{(\xi DC_\xi)_\xi}{R^2\xi}.$$

Q4材料速度和坐标变换相抵消，不能另加收缩对流。rho_d0=rho(C0,T0)/(1+C0)，rho_d(t)=rho_d0(R0/R)²；固定半径时自动退化为常数。

xi_i=1-(1-i/(N_r-1))²，i=0..N_r-1（**表面二次加密**，非均匀网格；用于解析干燥后期
低D区域在表面附近的薄边界层）。界面xi_{i+1/2}=(xi_i+xi_{i+1})/2，两端界面为0、1。
V_i=(xi_{i+1/2}²-xi_{i-1/2}²)/2。界面k、D取算术平均。
F^T_{i+1/2}=xi_{i+1/2} k_{i+1/2}(T_{i+1}-T_i)/(xi_{i+1}-xi_i)，F^C同理（**步长逐单元不同**）。
左端F=0；右端F^T=R h(T_inf-T_s)，F^C=-R h_m(C_s-C_inf)。
dT_i/dt=(F^T_right-F^T_left)/(R² V_i rho_i cp_i)，
dC_i/dt=(F^C_right-F^C_left)/(R² V_i)。
轴心控制体积自动得到4D(C_1-C_0)/Delta r²，不直接求1/r。
内部通量逐项抵消；同时积分损失率h_m(C_s-C_inf)/R，检查sum(V_i C_i)+累计损失守恒。
Q1同时积分R h(T_inf-T_s)，检查rho cp R² sum[V_i(T_i-T0)]等于累计加热。
Q2—4的变容量热方程验证瞬时离散收支，不错误宣称rho cp T的积分守恒。

## 2. 表面加密有限体积

令u_i=i/(Nr−1)，xi_i=1−(1−u_i)²；界面xi_(i+1/2)=(xi_i+xi_(i+1))/2，两端界面0、1。权重

$$V_i=\tfrac12(\xi_{i+1/2}^2-\xi_{i-1/2}^2).$$

内部面传输系数取相邻值算术平均：

$$F^T_{i+1/2}=\xi_{i+1/2}\frac{k_i+k_{i+1}}2
\frac{T_{i+1}-T_i}{\xi_{i+1}-\xi_i},$$
$$F^C_{i+1/2}=\xi_{i+1/2}\frac{D_i+D_{i+1}}2
\frac{C_{i+1}-C_i}{\xi_{i+1}-\xi_i}.$$

左面FT=FC=0，右面
$$F^T_{Nr-1/2}=R[h(T∞−Ts)−\Delta H_{vap}(Ts)j_v],\qquad
F^C_{Nr-1/2}=−Rj_v/\rho_d.$$

节点方程
$$\dot T_i=\frac{F^T_{i+1/2}-F^T_{i-1/2}}{R^2V_i\rho_ic_{p,i}},\qquad
\dot C_i=\frac{F^C_{i+1/2}-F^C_{i-1/2}}{R^2V_i}.$$

轴心控制体积自然处理圆柱奇性。均匀网格极限给4D(C1−C0)/Delta r²，不能直接在r=0除r。内部通量两两抵消，从构造上保留离散收支。

## 3. 守恒审计

附加累计状态A满足A'=jv/(rho_d R)，初值0，则
$$\sum_i V_iC_i+A=\frac{C_0}{2}.$$

因rho_d R²固定，乘2*pi*L*rho_d0*R0²即可恢复实际水质量。这一恒等式在Q4仍成立。

Q1常热容量下附加B'=R[h(T∞−Ts)−lambda*jv]，B(0)=0，核对
$$\rho c_pR_0^2\sum_iV_i(T_i−T_0)=B.$$

这是真正的当前有效模型显热/净边界收支。Q2—4变容量时只核对瞬时
$$R^2\sum_iV_i\rho_ic_{p,i}\dot T_i=R[h(T∞−Ts)−lambda*jv].$$

不能将积分rho*cp*T的变化当成上式时间积分而漏掉容量变化项，更不能宣称已验证完整多组分热力学能量守恒。残差接近机器精度只说明离散收支自洽，不说明物理模型真实。

## 4. 隐式积分和非光滑边界

采用SciPy BDF（自适应1—5阶），稀疏Jacobian；正式设置集中src/common/numerical_settings.py，当前1281节点、rtol=2e-10、atol=2e-11，前4h最大步长30s，之后60s。输出间隔不等于内部步长。

附件1每个线性插值节点、4h温湿切换、Q4附件2半径节点均分段重启积分。使用局部浓度变化尺度约1%的受限启动步长，避免积分器默认显式试探在最细表面单元越过C=0，不裁剪状态。min(js,jg)在活动分支切换处连续但通常不可微，误差由时间收紧及BDF/Radau比较检验，不能假定全程保持最高阶。

Jacobian必须含表面热与水方程对Ts和Cs的交叉依赖，累计水和净热量行也依赖二者。只沿用旧纯对流累计热行导数会遗漏潜热耦合。显式方法的允许步长随最小单元宽度平方缩小，表面二次加密后不采用固定1s显式推进。
