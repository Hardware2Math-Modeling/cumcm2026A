# 问题四：材料收缩与守恒的移动边界模型

Owner：`@model`。2026-09-11。物性用附录4，温湿控制与问题三相同，全部阶段保留汽化潜热。附件2是半径唯一来源，不从终点含水率反推半径。

## 1. 几何和干物质守恒

假定长度不变、径向均匀收缩，R(t)对附件2作线性插值，材料速度
$$v(r,t)=r\dot R/R.$$

题目只提供半径，未提供轴向变化，故不另造长度曲线。参考干密度
$$\rho_{d,0}=\frac{760+90C_0}{1+C_0},\qquad
\rho_d(t)=\rho_{d,0}\left(\frac{R_0}{R(t)}\right)^2.$$

因而干物质量 $M_d=\pi L R^2\rho_d=\pi L R_0^2\rho_{d,0}$ 恒定，满足
$$\partial_t\rho_d+\frac1r\partial_r(r\rho_dv)=0.$$

附录4的 rho(C) 只用于题定有效热容量，不强制与 rho_d(t)(1+C) 相等，否则半径、浓度与经验密度通常构成过定系统。本模型保证参考干物质与水分收支，不声称建立了孔隙、应力和混合物密度的完整闭合。

## 2. 欧拉守恒式与材料变换

相对材料水通量为 -rho_d D C_r，水分守恒为
$$\partial_t(\rho_d C)+\frac1r\partial_r(r\rho_d C v)
=\frac1r\partial_r(r\rho_dD C_r).$$

利用干物质连续性及空间均匀rho_d得
$$C_t+vC_r=\frac1r\partial_r(rDC_r),\qquad
\rho c_p(T_t+vT_r)=\frac1r\partial_r(rkT_r).$$

令xi=r/R(t)，则
$$\left.\partial_t\right|_r=\left.\partial_t\right|_\xi
-\frac{\xi\dot R}{R}\partial_\xi,\qquad
\partial_r=R^{-1}\partial_\xi,\qquad
v\partial_r=\frac{\xi\dot R}{R}\partial_\xi.$$

两项抵消，固定材料域0≤xi≤1上
$$\left.\partial_tC\right|_\xi=\frac1{R^2\xi}\partial_\xi(\xi D C_\xi),\qquad
\rho c_p\left.\partial_tT\right|_\xi=\frac1{R^2\xi}\partial_\xi(\xi kT_\xi).$$

禁止再次添加xi*Rdot/R*C_xi，否则重复计算材料运动。仅变换没有材料输运的欧拉扩散式会出现该项，但它是不同模型。

## 3. 初边值和蒸发

初值T0、C0；中心T_xi=C_xi=0。表面通量使用environment.md同一闭合，但供水能力中使用当前rho_d(t)：
$$j_s=\rho_d(t)h_mC_s,\quad j_g=K_M(Y_{sat}(T_s)-Y_\infty),\quad j_v=\min(j_s,j_g).$$
$$D_sC_\xi=-Rj_v/\rho_d(t),\qquad
k_sT_\xi=R\{h(T_\infty-T_s)-\Delta H_{vap}(T_s)j_v\}.$$

通量相对移动材料表面，不能把边界扫掠体积又算成蒸发。R变化同时影响内部R^-2输运尺度与rho_d对应的供水潜热。

## 4. 数值和验证

采用表面加密材料网格及有限体积，在附件2半径插值节点重启积分。Rdot已消去，无须对离散半径求噪声导数。

控制体积为2*pi*L*R²*V_i，干物质量权重2*pi*L*rho_d*R²*V_i恒定；验证
$$\frac{\mathrm d}{\mathrm dt}\int_0^{R(t)}2\pi Lr\rho_d(t)C(r,t)\,\mathrm dr
=-2\pi LR(t)j_v(t).$$

固定半径退化对照必须用附录4与R0，才能隔离几何效果；问题三与四直接比较同时改变物性和几何。不能把二者时长差全部归为收缩。

附件2末端半径平台不等于含水率达标。若72 h内没达到C<0.15，应报告失败，不能无依据外推R(t)。自定工况下仍使用题给半径，视为外部强制数据；没有不同工况的收缩实验，不能声称它是60°C/20%RH下实测曲线。
