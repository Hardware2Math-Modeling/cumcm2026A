## 1. 几何和干物质守恒

假定长度不变、径向均匀收缩，R(t)对附件2作线性插值，材料速度
$$v(r,t)=r\dot R/R.$$

题目只提供半径，未提供轴向变化，故不另造长度曲线。参考干密度
$$\rho_{d,0}=\frac{760+90C_0}{1+C_0},\qquad
\rho_d(t)=\rho_{d,0}\left(\frac{R_0}{R(t)}\right)^2.$$

因而干物质量 $M_d=\pi L R^2\rho_d=\pi L R_0^2\rho_{d,0}$ 恒定，满足
$$\partial_t\rho_d+\frac1r\partial_r(r\rho_dv)=0.$$

这是一个**移动边界问题**。两条实现路线的难度差一个数量级：

| 方案 | 做法 | 复杂度 | 风险 |
|---|---|---|---|
| **A. 坐标变换** | 令 $\xi = r/R(t) \in [0,1]$，把移动域映射到固定计算域 | 低 | 推导中会出现对流项，但它与链式法则项**恰好相消**（§3.5）；误加会重复计入（§3.9） |
| **B. 移动网格 / ALE** | 网格节点随边界移动 | 高 | 3 天赛程不建议 |
| **C. 离散缩放** | 直接用附件 2 的 $R(t)$ 表格按比例缩放固定网格 | 低 | 等价于 A 的离散版 |

**本项目实现的是方案 A**（`docs/DECISIONS.md` D-006；`src/common/radial.py` 全程使用
$\xi$ 网格 + $R(t)$ 缩放，从不重划网格）。三点说明：

1. 在**径向均匀材料收缩**的假设下（§2 假设 2），材料速度恰好等于 $\xi\dot R$，
   网格节点 $\xi_i$ 固定不动而物理位置 $r_i(t) = \xi_i R(t)$ 随材料移动——
   也就是说 **A 在数学上就是 B 的拉格朗日特例**，但不需要任何动网格/remapping 实现。
   这是选 A 的实际理由，而不是"图省事"。
2. 方案 C 与 A 在此意义下等价（C 就是 A 的离散写法），**不作为独立实现**，
   故不存在"A 与 C 结果不一致"的风险。
3. 关键推导见 §3；推导里有一处**严格相消**，它决定了代码里**不能**出现对流项（§3.9 的警告）。

利用干物质连续性及空间均匀rho_d得
$$C_t+vC_r=\frac1r\partial_r(rDC_r),\qquad
\rho c_p(T_t+vT_r)=\frac1r\partial_r(rkT_r).$$

令xi=r/R(t)，则
$$\left.\partial_t\right|_r=\left.\partial_t\right|_\xi
-\frac{\xi\dot R}{R}\partial_\xi,\qquad
\partial_r=R^{-1}\partial_\xi,\qquad
v\partial_r=\frac{\xi\dot R}{R}\partial_\xi.$$

两项抵消，固定材料域0≤xi≤1上
$$\left.\partial_tC\right|_\xi=\frac1{R^2\xi}\partial_\xi(\xi D C_\xi),\qquad
\rho c_p\left.\partial_tT\right|_\xi=\frac1{R^2\xi}\partial_\xi(\xi kT_\xi).$$

### 3.1 收缩运动学

由假设 2，物质点满足 $r = (R(t)/R_0)r_0$。对固定物质点求时间导数得**材料速度**

$$v(r,t) = \left.\frac{\partial r}{\partial t}\right|_{r_0} = \frac{\dot R}{R_0}r_0 = \frac{\dot R}{R}\,r = \xi\,\dot R$$

（`numerics.md` 第 13 行：$v = r\dot R/R$。）

### 3.2 干物质连续性 $\Rightarrow$ 干基表观密度

单位**当前**体积的干物质质量为 $\rho_d(t)$。长度不变 + 径向均匀收缩 ⇒ 半径 $R$ 的圆柱内干物质质量
$\propto R^2$，故 $\rho_d(t)R(t)^2 = \rho_d(0)R_0^2$，即

$$\rho_d(t) = \rho_d(0)\left(\frac{R_0}{R(t)}\right)^2 \tag{3.1}$$

**自洽性检验**（干物质连续性方程；径向均匀收缩 ⇒ $\partial \rho_d/\partial r = 0$）：

$$\frac{\partial \rho_d}{\partial t} + \frac{1}{r}\frac{\partial (r\rho_d v)}{\partial r}
= -\frac{2\rho_d\dot R}{R} + \frac{1}{r}\frac{\partial}{\partial r}\!\left(\rho_d\frac{r^2\dot R}{R}\right)
= -\frac{2\rho_d\dot R}{R} + \frac{2\rho_d\dot R}{R} = 0 \quad\checkmark$$

（这就是 `numerics.md` 第 14 行"由干物质连续性"的内容。）

### 3.3 水分守恒（干基）$\Rightarrow$ 固定坐标下的原方程

以干基 $\rho_d C$ 写水分守恒，"相对材料"的扩散通量为 $-\rho_d D\,\partial_r C$：

$$\frac{\partial (\rho_d C)}{\partial t} + \frac{1}{r}\frac{\partial (r\,\rho_d C\,v)}{\partial r}
= \frac{1}{r}\frac{\partial}{\partial r}\!\left(r\,\rho_d D\,\frac{\partial C}{\partial r}\right)$$

左端展开（$\rho_d$ 与 $r$ 无关）：

$$\rho_d\,\frac{\partial C}{\partial t}
+ C\underbrace{\left(\frac{\partial \rho_d}{\partial t} + \frac{\rho_d}{r}\frac{\partial (r v)}{\partial r}\right)}_{=\,0\ \text{（§3.2）}}
+ \rho_d\,v\,\frac{\partial C}{\partial r},
\qquad \frac{1}{r}\frac{\partial (rv)}{\partial r} = \frac{1}{r}\frac{\partial}{\partial r}\!\left(\frac{r^2\dot R}{R}\right) = \frac{2\dot R}{R}$$

$C$ 的系数括号里两项（$-\frac{2\rho_d\dot R}{R}$ 与 $\frac{2\rho_d\dot R}{R}$）**相消**——
这是**第一处相消，来自干物质守恒，不是链式法则**。右端 $\rho_d$ 同样可提出，两边约去后得

$$\boxed{\frac{\partial C}{\partial t} + v\,\frac{\partial C}{\partial r} = \frac{1}{r}\frac{\partial}{\partial r}\!\left(r D\,\frac{\partial C}{\partial r}\right)} \tag{3.2}$$

（`numerics.md` 第 14 行：$C_t + vC_r = (rDC_r)_r/r$。）注意此时**还必须保留** $vC_r$ 项。

### 3.4 坐标变换的链式法则

令 $\xi = r/R(t)$，固定 $\xi$ 对应 $r = \xi R(t)$：

$$\left.\frac{\partial}{\partial r}\right|_{t} = \frac{1}{R}\left.\frac{\partial}{\partial \xi}\right|_{t},
\qquad
\left.\frac{\partial \xi}{\partial t}\right|_{r} = -\frac{r\dot R}{R^2} = -\frac{\xi \dot R}{R}$$

$$\left.\frac{\partial}{\partial t}\right|_{r}
= \left.\frac{\partial}{\partial t}\right|_{\xi} + \left.\frac{\partial \xi}{\partial t}\right|_{r}\frac{\partial}{\partial \xi}
= \left.\frac{\partial}{\partial t}\right|_{\xi} - \frac{\xi \dot R}{R}\frac{\partial}{\partial \xi} \tag{3.3}$$

### 3.5 相消（**必须逐项看清楚**）

把 (3.3) 与 $v = \xi\dot R$、$\partial_r = R^{-1}\partial_\xi$ 代入 (3.2) 的左端：

$$
\underbrace{\left.\frac{\partial C}{\partial t}\right|_{r}}_{=\ C_t|_\xi - \frac{\xi\dot R}{R}C_\xi}
\; + \; v\underbrace{\frac{\partial C}{\partial r}}_{=\ C_\xi/R}
\;=\;
C_t\big|_\xi \;-\; \frac{\xi \dot R}{R}C_\xi \;+\; (\xi\dot R)\frac{C_\xi}{R}
\;=\;
C_t\big|_\xi \;-\; \frac{\xi\dot R}{R}C_\xi \;+\; \frac{\xi\dot R}{R}C_\xi
\;=\; C_t\big|_\xi
$$

**链式法则带来的输运项 $-\frac{\xi\dot R}{R}C_\xi$ 与材料速度带来的对流项 $vC_r = +\frac{\xi\dot R}{R}C_\xi$
完全相同、符号相反，严格相消。** 换言之

$$\frac{DC}{Dt} \;:=\; \left.\frac{\partial C}{\partial t}\right|_{r} + v\,\frac{\partial C}{\partial r} \;=\; \left.\frac{\partial C}{\partial t}\right|_{\xi}$$

即**物质导数就是固定 $\xi$ 的偏导数**。这不是巧合：由 §3.8，$\xi$ 本身被材料速度平流。

右端：

$$\frac{1}{r}\frac{\partial}{\partial r}\left(r D\,\frac{\partial C}{\partial r}\right)
= \frac{1}{\xi R}\cdot\frac{1}{R}\frac{\partial}{\partial \xi}\!\left(\xi D\,\frac{\partial C}{\partial \xi}\right)
= \frac{1}{R^2\,\xi}\frac{\partial}{\partial \xi}\!\left(\xi D\,\frac{\partial C}{\partial \xi}\right)$$

### 3.6 变换后的方程（最终形式）

$$\boxed{\;\left.\frac{\partial C}{\partial t}\right|_{\xi} = \frac{1}{R^2\,\xi}\frac{\partial}{\partial \xi}\!\left(\xi D\,\frac{\partial C}{\partial \xi}\right),
\qquad
\rho c_p\left.\frac{\partial T}{\partial t}\right|_{\xi} = \frac{1}{R^2\,\xi}\frac{\partial}{\partial \xi}\!\left(\xi k\,\frac{\partial T}{\partial \xi}\right)\;}$$

（`numerics.md` 第 16 行。热方程沿用 §2 的有效显热容量口径：
$\rho, c_p, k$ 均为当地 $(C,T)$ 的函数，$C$ 与 $T$ 通过附录 4 双向耦合。）

**新增的"项"只有 $1/R^2$ 这个整体系数，没有任何对流项。**
物理含义：$\xi$ 坐标下所有长度都按 $R(t)$ 缩放，扩散算子只有 $1/R^2$ 的加速/减速因子；
特征扩散时间 $\sim R^2/D$ 随 $R$ 减小而**缩短**。

**代码落点**（`src/common/radial.py` 第 45–64 行，逐行对应本节）：

| 数学量 | 代码 |
|---|---|
| $R(t)$ | `R = self.radius(t)`（moving 时取 `boundary.radius(t)`，否则取 $R_0$） |
| 界面通量 $\xi_{i+1/2}D_{i+1/2}(C_{i+1}-C_i)/\Delta\xi$ | `qC[1:-1] = faces[1:-1]*(D[1:]+D[:-1])/2*np.diff(C)/np.diff(xi)`（界面 $k,D$ 取**算术平均**） |
| 表面通量 $-R h_m(C_s-C_\infty)$、$R h(T_\infty-T_s)$ | `qC[-1] = -R*outward_flux(...)`、`qT[-1] = -R*outward_flux(...)` |
| $C_t\vert_\xi = (\text{通量差})/(R^2 V_i)$ | `dC = np.diff(qC)/(R*R*self.weights)`；热方程同式除以 $V_i\rho_ic_{p,i}$ |
| 无对流项 | `rhs` 中**没有任何** $v$ 或 $\dot R$ 出现（与 §3.9 警告一致） |

### 3.7 表面条件在变换后的形式

由 $D\,C_r = -h_m(C_s-C_\infty)$（`numerics.md` 第 8 行）与 $\partial_r = R^{-1}\partial_\xi$：

$$\boxed{\;D\left.\frac{\partial C}{\partial \xi}\right|_{\xi=1} = -R\,h_m\,(C_s - C_\infty),
\qquad
k\left.\frac{\partial T}{\partial \xi}\right|_{\xi=1} = R\,h\,(T_\infty - T_s)\;}$$

（`numerics.md` 第 17 行。）$\xi = 1$ 是**固定边界**，对任意 $t$ 都成立。
系数里多出的 $R$ 是把"对 $r$ 的梯度"换成"对 $\xi$ 的梯度"的几何因子（梯度被拉长了 $1/R$ 倍），
它与方程里的 $1/R^2$ 一起决定失水与传热速率——这是 §11.2 量化两个相反效应的关键。

### 3.8 为什么 $\xi$ 就是物质坐标

1. **定义层面**：由假设 2，$r_0/R_0 = \xi$ 对同一团干物质**恒定不变**。
   所以固定 $\xi$ 的点永远跟踪同一团材料；$\xi$ 不是数学技巧，而是"材料标签"。
2. **等价判据**：$\xi$ 被材料速度平流，是一个材料守恒量：
   $$\xi_t + v\,\xi_r = -\frac{\xi\dot R}{R} + (\xi \dot R)\cdot\frac{1}{R} = 0$$
   因此 $\left.\partial_t\right|_\xi$ 就是物质导数——§3.5 的相消是这一事实的代数后果。
3. **数值后果**：内部网格节点 $\xi_i$ 固定，其物理位置 $r_i(t) = \xi_i R(t)$ 自动随材料移动；
   交付时按 $r_i(t)$ 逐行插值即可（§6.4）。**不需要动网格、不需要 remapping、
   不需要 $\dot R$**（§1.1 结论 1）。
4. **退化检验**（`AGENTS.md`/骨架要求的极限情形）：取 $R \equiv R_0$（$\dot R = 0$），
   (3.6) 退化为固定域方程
   $C_t = (\xi D C_\xi)_\xi/(R_0^2\xi)$，配合 $D C_\xi = -R_0h_m(C_s-C_\infty)$，
   与问题三的方程在缩放坐标下完全一致。
   **代码级验证**：`tests/test_numerics.py::test_constant_radius_reduces_to_fixed_model`
   把附件 2 的 $R$ 全部置为 $R_0$ 后比较 moving 与 fixed_radius 两种模式的右端，
   断言 `atol=0`（逐位相同，实测通过）。

### 3.9 ⚠️ 警告：不得在本材料坐标模型上再加 $(\xi\dot R/R)\,C_\xi$ 项

> **`docs/model/numerics.md` 第 18 行原文**：
> "不得在这个材料坐标模型上再次添加 $\xi\dot R/R\,C_\xi$；该项仅对应没有材料速度的另一种欧拉模型。"
> 同一条警告已作为**已否决方案**记录在 `docs/DECISIONS.md` **D-013 ❌**（"在材料坐标方程上再加一个
> $\xi\dot R/R$ 对流项"），其中还保留了 2026-09-11 复核会话中"一度误判此处漏了对流项"的经过。
>
> **为什么它已经相消**：§3.5 逐项显示，链式法则产生的 $-\frac{\xi\dot R}{R}C_\xi$ 与材料速度
> 产生的 $+\frac{\xi\dot R}{R}C_\xi$ 大小相同、符号相反。**再加一次就是重复计入，
> 等价于凭空引入一个不存在的相对流动，会系统性偏移干燥速率。**
>
> **什么情况下才需要那一项**：只有当**坐标变换不再与材料运动同步**时才需要，例如
> (i) 在**固定物理坐标** $r$ 上求解而边界在动（纯欧拉观点），
> (ii) 假设**非均匀收缩**（有径向的相对材料速度，§2 假设 2 的代价），
> (iii) 用**不随材料缩放的固定网格**做离散（方案 C 的误用）。
> 本项目三者都不是：网格节点是材料点（§3.8-3），故不出现该项。
>
> **判据（给未来的 AI 或维护者）**：若有人"发现方程少了一项"并提出"修正"，
> 先问一句——**这个模型的网格节点是材料点还是空间点？**
> 若是材料点（本项目），加那一项就是错的；给出"修正"必须同时给出**新模型 + 新 DECISIONS 条目 + 重跑 q4**。

空白只在导出层按半径掩码生成；内部场全有限，写出器硬校验掩码。论文表6标注空白含义。时间每60 s至首个严格合格整分钟，连续阈值与半径单独存摘要与最后展示行。

### 4.1 初始条件

$$T(\xi,0) = 301.15\ \text{K}\ (28\ ^\circ\text{C}),\qquad C(\xi,0) = 2.55\ \text{kg/kg（干基）},\qquad \xi \in [0,1]$$

$t = 0$ 时 $R(0) = R_0$，故初始条件与前三问逐字相同；均匀场在 $\xi$ 与 $r$ 两种坐标下也相同
（`radial.py` `initial()`：全场常数初值 + 两个累计量初值 0）。

### 4.2 边界条件

- **轴心 $\xi = 0$**：由对称性
  $$\left.\frac{\partial T}{\partial \xi}\right|_{\xi=0} = \left.\frac{\partial C}{\partial \xi}\right|_{\xi=0} = 0$$
  数值上不直接求 $1/\xi$：节点中心有限体积的左端界面通量取 0
  （`radial.py` 第 55 行 `qT, qC = np.zeros(n+1)`，左端保持 0），
  轴心控制体自动得到 $4D(C_1-C_0)/\Delta r^2$ 形式
  （`numerics.md` 第 29 行），**不出现 $1/r$ 奇性**。
- **表面 $\xi = 1$**：对流 + 题给浓度差的传质（§3.7），
  即 $D C_\xi = -Rh_m(C_s-C_\infty)$、$k T_\xi = R h(T_\infty-T_s)$。
  **这里没有独立的"蒸发耗热"项**（假设与问题二一致：不另加潜热），
  因此热边界与质边界**不直接耦合**，耦合只通过物性 $\rho(C,T),c_p(C,T),k(C,T),D(C,T)$ 发生。

> 表面通量是**相对于移动边界**的通量：$\xi=1$ 是材料表面点，
> 其物理位置 $r=R(t)$ 在动；(3.7) 已把这一运动学全部吸收进系数中的 $R$（§3.7、§11.2）。

### 6.1 空间离散

**用固定的 $\xi$ 均匀/加密网格，不用物理网格**——因为 $\xi$ 是材料坐标（§3.8），

### 6.2 时间离散

`scipy.integrate.solve_ivp(method="BDF")`，稀疏 Jacobian（六色有限差分），
rtol $2\times10^{-9}$ / atol $2\times10^{-10}$，分段 `max_step`：$t<14400$ s 时 30 s，之后 120 s

### 6.3 边界条件的离散实现（系数级别）

以节点中心有限体积写，界面通量 $q$ 定义在 $n+1$ 个界面上
（`radial.py` 第 54–64 行）：

$$q^T_{i+1/2} = \xi_{i+1/2}\,\frac{k_i+k_{i+1}}{2}\,\frac{T_{i+1}-T_i}{\Delta \xi_i},
\qquad q^C_{i+1/2} = \xi_{i+1/2}\,\frac{D_i+D_{i+1}}{2}\,\frac{C_{i+1}-C_i}{\Delta \xi_i}$$

$$q^T_{0} = q^C_{0} = 0 \quad(\text{对称性}),\qquad
q^T_{N} = -R\,h\,(T_N - T_\infty),\qquad q^C_{N} = -R\,h_m\,(C_N - C_\infty)$$

$$\frac{dT_i}{dt} = \frac{q^T_{i+1/2}-q^T_{i-1/2}}{R^2\,V_i\,\rho_i c_{p,i}},
\qquad
\frac{dC_i}{dt} = \frac{q^C_{i+1/2}-q^C_{i-1/2}}{R^2\,V_i}$$

（`numerics.md` 第 25–28 行；代码里 `outward_flux(value_surface, value_ambient, coef) = coef*(value_surface - value_ambient)`，
加热时返回负值，`tests/test_numerics.py::test_boundary_sign_and_equilibrium` 守门。）

**质量审计行**：额外积分两个标量状态——归一化累计失水量与累计加热量
（`radial.py` 第 41–43、62–64 行）：

$$\frac{d}{dt}(\text{累计失水量}) = \frac{h_m(C_s-C_\infty)}{R},
\qquad \sum_i V_i C_i + (\text{累计失水量}) = \sum_i V_i C_i(0) = \tfrac12 C_0$$

（损失率的表达式与 `numerics.md` 第 30 行一致；实现里由 $-\text{diff}(q^C)$ 末项/$R^2$ 得到。）
累计量两行在 Jacobian 里用解析导数而非差分（`radial.py` 第 80–106 行），
避免严格零导数列被反复放大。

### 11.2 两个方向相反的效应，在本模型里的归属

骨架列出的两个效应是：

| 效应 | 直觉方向 | 对干燥时长的影响 |
|---|---|---|
| 表面积减小 | 水分逸出通道变小 | 变**长** |
| 传质路径缩短 | 中心到表面距离变短 | 变**短** |

在本模型里必须把两者换算到**同一个度量**上才能比较，否则会得出错误的定性结论。
把 §3.6 的方程对材料测度积分（$\int_0^1(\cdot)\,\xi\,d\xi$，即代码的 $\sum_i V_i C_i$），
并代入 §3.7 的表面条件：

$$\frac{d}{dt}\int_0^1 C\,\xi\,d\xi
= \frac{1}{R^2}\Big[\xi D C_\xi\Big]_{\xi=0}^{\xi=1}
= \frac{D C_\xi(1)}{R^2}
= -\frac{h_m\,(C_s - C_\infty)}{R}$$

即"单位材料测度的失水速率" $= h_m\Delta C/R$（与 `numerics.md` 第 30 行给出的损失率
$h_m(C_s-C_\infty)/R$ 完全一致）。再把它换成**单位长度药材的失水质量**：
由 §3.2 的 $\rho_d(t)R(t)^2 \equiv \text{const}$，

$$W = \rho_d(t)R^2\cdot 2\pi\int_0^1 C\xi\,d\xi
\;\Longrightarrow\;
\frac{dW}{dt} = -\,2\pi R\;\underbrace{\rho_d(t)}_{\propto\,R^{-2}}\;h_m\,(C_s-C_\infty)$$

于是两条通道各自的量纲因子是：

| 通道 | 因子 | 随 $R$ 减小 |
|---|---|---|
| 表面积（外围逸出面积 $\propto R$） | $R$ | 变**小**（趋于变慢） |
| 干基密度（材料被压实，$\rho_d\propto R^{-2}$） | $R^{-2}$ | 变**大**（趋于变快） |
| **净表面项** | $R^{-1}$ | **变快** |
| **内部再分布（扩散时间尺度 $R^2/D$）** | $R^{2}$ | **变快** |

**结论（属本模型的推论，务必如实陈述）**：在已实现的闭合下，
"表面积减小"这一条**没有**表现为净减速——因为表面传质沿用了前三问的干基形式
$D C_r = -h_m\Delta C$，而干基密度随收缩上升（$\propto R^{-2}$），
把面积因子 $R$ 完全抵消并超过。两个通道**都指向变快**，
量化后的净效应与 $R^2/D$ 标定一致：观测比值
$50.8242/129.0926 = 0.394$，与 $(R_{\text{end}}/R_0)^2 = (1.2000/2.0000)^2 = 0.360$ 同量级，
且 §5 算出 $h_mR/D \approx 25 \gg 1$（**内部扩散控制**）——
后者的时间尺度正是 $R^2/D$，因此"路径缩短"占主导。

> ⚠️ **论文里的措辞要求**：可以写"在本模型下收缩使干燥加快，量级与扩散时间 $\propto R^2/D$ 一致"；
> **不要**写"面积减小使干燥变慢，但路径缩短胜出"——
> 那会与本模型的推导矛盾（面积因子在本闭合下不产生净减速）。
> 若评审或题目预期的物理机制是"面积减小 → 变慢"，
> 那需要换表面传质闭合（属**新模型**：需新建 `docs/DECISIONS.md` 条目、重跑全部 q4），
> **不得**通过"在材料坐标方程里再加 $\xi\dot R/R\,C_\xi$ 项"来制造这个效应（见 §3.9 警告）。
