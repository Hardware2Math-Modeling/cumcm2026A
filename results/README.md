# 四问潜热模型与两种恒温方案

主方案 `result1.xlsx`—`result4.xlsx`：前4h采用附件1（Q1仅计算30min），之后60°C、20%RH。Q1用附录2，Q2/Q3全程用附录3，Q4用附录4及附件2半径；全部计入相变潜热。

第二方案位于 `scenarios/fitted_temperature/`：前4h相同，之后取附件温度曲线的拟合平台约50.0082°C，相对湿度仍20%。该目录提供独立的 `result2.xlsx`—`result4.xlsx`，Q1与主方案相同。

工作簿按原模板表名/列名，每个数四位小数，时间单位均为秒。Q2保留全过程每秒数据（包含题目展示的前3h）；Q3/Q4每60s直到首个严格达标的输出点。Q4固定位置超出当前半径时留空，末列始终为当前表面。不可把空白当0，也不可把显示0.1500当作未舍入数值严格大于等于0.15。

连续阈值事件、严格达标输出时刻、质量残差、源文件SHA256等保存在各 `qN_summary.json` 与 `qN_manifest.json`。对应论文表格位于 `tables/`，图表由Python自动生成。

这些是当前一维供水/气膜互补模型下的条件性计算：未知药材的吸附等温线、结合水附加解吸热和端面效应未识别。Q4极薄表层没有得到统一全场四位精度保证；指定输出位置与终点的加密比较见 `validation/q4_boundary_layer.json`。
