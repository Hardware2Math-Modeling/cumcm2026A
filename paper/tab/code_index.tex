\subsection*{支撑材料文件列表}
本节列出支撑本论文模型、结果与结论的全部程序与数据文件。以下源代码均与随文提交的支撑材料一致，可直接运行复现论文中的全部数值结果。
\begin{itemize}\itemsep1pt
  \item \texttt{src/common/numerical\_settings.py}：正式数值设置（网格与误差容差）
  \item \texttt{src/common/correlations.py}：附录 2/3/4 三套物性公式集与单位校验
  \item \texttt{src/common/boundary.py}：附件 1/2 的读取、分段线性插值与半径不可外推约束
  \item \texttt{src/common/problem\_spec.py}：四个问题的规格定义（几何、初值、判据、参数集）
  \item \texttt{src/common/radial.py}：核心求解器：材料坐标有限体积 + 自适应 BDF + 事件检测
  \item \texttt{src/common/export.py}：内部解到交付网格的映射（含问题 4 的域外留空）
  \item \texttt{src/common/io\_excel.py}：交付文件写出与格式硬校验
  \item \texttt{src/q1/solver.py}：问题一求解入口
  \item \texttt{src/q4/solver.py}：问题四求解入口（材料坐标与收缩）
  \item \texttt{scripts/\_runner.py}：单问执行流程（求解 → 交付 → 展示表 → 清单）
  \item \texttt{scripts/run\_all.py}：四问一次性执行入口
  \item \texttt{scripts/make\_tables.py}：论文表格与数值宏的生成
  \item \texttt{scripts/make\_figs.py}：论文插图的生成
  \item \texttt{scripts/make\_code\_appendix.py}：本附录自身的生成脚本
  \item \texttt{scripts/validate\_numerics.py}：守恒、网格加密与环境外推灵敏度验证
  \item \texttt{scripts/validate\_accuracy.py}：网格/时间精度、Bessel 解析解与 Radau 交叉验证
  \item \texttt{scripts/verify\_accuracy\_outputs.py}：交付文件全单元格回读与 SHA-256 校验
  \item \texttt{tests/test\_numerics.py}：数值正确性回归测试
\end{itemize}
此外，支撑材料还包含：交付结果文件 \texttt{results/result1$\sim$4.xlsx}；验证报告 \texttt{results/validation/*.json}（网格加密、时间精度、灵敏度、解析解对照与独立复算）；论文插图的矢量源文件 \texttt{paper/figs/*.pdf}；附件 1、附件 2 的解析结果 \texttt{data/processed/*.csv}；以及题面要求的说明见附录~\ref{app:ai}。
